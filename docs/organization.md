## 데이터 전환 (저장 데이터 v6 → v7, `src/domain/reorg.ts`)

- 새 데이터와 이전 브라우저 데이터가 **같은 함수**를 거친다(새 시드 = 이전 구조 시드 + 전환).
- 원래 시드 값과 **그대로 같은** 항목만 바꾼다: 원래 이름인 직원만 새 이름, 원래 팀에 그대로 있는 시드 직원만 이동, 원래 이름인 팀만 이름 변경. 사용자가 추가·수정한 직원·팀·이름은 그대로 두고 충돌로 기록한다(사용자 직원이 남은 기존 팀은 숨기지 않음).
- 다시 실행해도 바뀌는 것이 없다(이름·소속이 이미 새 값이면 건너뜀). 화면은 저장 버전이 7이면 다시 전환하지 않는다.
- 변환 전 데이터는 `daeyang-hr-mockup-v1-before-v7`에 한 번 보관한다(복원용). 전환 메모는 `daeyang-hr-mockup-v1-migration-notes`.
- 직원 ID·사번·로그인 연결(직원 ID)·평가 배정·응답·원점수·보정·최종 지정·진행 상태·변경 이력은 그대로.
- **확정 회차**: 대상자 스냅샷(그때의 소속·이름)과 KPI·보정을 바꾸지 않는다.
- **확정 전 회차(시연 회차)**: 대상자 스냅샷의 소속을 네 팀으로, 이름을 새 이름으로 정리. 팀장 여부·평가 경로·배정은 회차 시작 시점 그대로(배정을 다시 만들지 않음).

## 팀장 지정안 (확인 필요)

여러 팀이 합쳐져 팀장 후보가 여러 명이 됐다. 합쳐지는 쪽(새 팀 레코드를 이어 쓰는 팀)의 기존 팀장을 유지하고, 나머지는 팀원이 된다. 직급은 바꾸지 않았다.

| 새 팀 | 유지한 팀장 | 팀원이 된 기존 팀장 |
|---|---|---|
| 경영기획팀 | 이준호 | 강태영(영업팀), 송하은(관리팀) |
| 생산팀 | 오정훈 | 배진우(생산지원부 생산팀) |

- 시연 회차에서는 세 사람이 여전히 "팀장" 경로(자기평가 → 임원평가)이고, 강태영은 윤서준·조은비의 2단계 팀장평가 평가자로 남아 있다(배정을 다시 만들지 않음). 다음 회차를 만들면 현재 조직 기준으로 배정된다.
- 다른 사람을 팀장으로 하려면 조직 관리 → 팀 관리에서 바꾼다.

## KPI·팀 보정 (재설정 필요 항목)

옛 부서와 새 팀이 1:1인 경우만 새 팀으로 옮겼다. 여러 부서가 한 팀이 되거나 한 부서가 나뉜 경우는 평균·합산·임의 선택·0점 대체를 하지 않고 원래 기록을 옛 키 그대로 보존했다.

| 회차 | 기록 | 처리 | 필요한 조치 |
|---|---|---|---|
| 2026 하반기 | 기술부 KPI 92 (직접 입력) | 설계팀으로 이동 (1:1) | 없음 |
| 2026 하반기 | 경영지원부 KPI 88 (직접 입력) | 보존(새 팀에 적용 안 함) — 경영기획팀 = 경영지원부 + 관리부 | 경영기획팀 KPI 새로 입력 |
| 2026 하반기 | 생산부 KPI 0 (직접 입력) | 보존(새 팀에 적용 안 함) — 생산부가 생산팀·현장팀으로 나뉨 | 생산팀·현장팀 KPI 새로 입력 |
| 2026 하반기 | 생산부 팀 보정 +1 | 보존하고 **그 부서였던 대상자 8명에게 계속 적용**(대상자 스냅샷의 `legacyUnitId`) — 최종 점수 변동 없음 | 새 팀 기준으로 바꾸려면 결과 화면에서 생산팀·현장팀 팀 보정 입력(입력하면 새 값 우선) |

- 이 회차는 KPI 반영이 꺼져 있어 KPI 기록 처리로 바뀐 점수는 없다. 반영을 켜면 경영기획팀·생산팀·현장팀은 "KPI 입력 필요"로 표시되고 최종 점수는 계산되지 않는다(0점으로 대신하지 않음).
- 정리 전후 모든 대상자의 원점수·기초 점수·팀/개인 보정·최종 지정·최종 점수가 같음을 자동 테스트로 확인했다.

## 로그인 (시연, 실제 인증 아님)

- 직원·팀장·임원: 아이디 = **새 이름**, 비밀번호 = 사번(앞자리 0 포함). 예: 이준호 / 0004, 최유진 / 0005, 김도현 / 0002, 바크트 오스모노프 / 0016

## 직급 세 가지·임원 4명 (D-068)

- 직급은 **임원·팀장·사원** 세 가지다. 이전의 세부 직급 글자(대표이사·이사·상무·차장·반장·대리 등)는 v8 변환에서 임원(임원·대표자) / 팀장(실제 팀장 연결) / 사원(나머지)으로 바뀌었다. 위 표의 괄호 속 세부 직급은 변환 전 기록이다.
- 임원 4명: 홍성훈·김도현·박재원·전상철 — **가상 목업 데이터**이며, 임원을 모든 대상자에게 자동 배정하지 않고 인원 제한도 없다.
- 팀장 4명: 이준호(경영기획팀)·장현우(설계팀)·오정훈(생산팀)·권민혁(현장팀). 강태영·송하은·배진우는 사원이다(시연 회차 스냅샷에서는 회차 시작 시점대로 팀장 경로 유지).
- 단계·자기평가 규칙은 docs/stages.md.
