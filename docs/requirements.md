## 진행현황 설명 보관 (화면에서 제거, 2026-10-27)

화면에서 지운 두 접이식 영역의 내용이다. 기능·집계 방식은 바뀌지 않았다.

**집계 기준**
- 요약 카드는 검색·필터와 관계없이 선택한 회차 전체 기준이며, 단위는 모두 사람(대상자)이다.
- 평가 대상자: 이 회차에 포함되고 재직 중이며 평가 제외가 아닌 사람.
- 모든 단계 제출 완료: 그 사람에게 필요한 단계가 모두 제출된 인원. "해당 없음" 단계는 세지 않으며 대표 확정 여부와 무관.
- n단계 제출: 그 단계가 실제로 배정된 대상자 중 제출이 끝난 인원. 한 단계에 평가자가 여럿이면 모두 제출해야 완료. 평가자가 배정되지 않은 단계는 분모에서 빠지고 그 사람은 미완료.

**목업 안내**
- 모든 인원·응답은 가상 데이터이며 저장은 브라우저(localStorage)에만 된다. 서버 저장 아님.
- 실제 로그인, 링크 만료·재발급·폐기, 자동 문자·푸시 발송은 구현되지 않았다.
- "개인 링크 복사"의 주소는 이 목업에서만 열리는 시연용 주소다.
- "평가 목록 열기"는 해당 평가자 화면으로 바꿔 보여주는 시연용 역할 전환이며 실제 인증이 아니다.
- 진행현황은 제출 여부만 보여주고 점수·등급은 표시하지 않는다. 대표자 최종 확정은 결과·리포트에서 다룬다.
- 단계 순서는 회사 확정 전 개발용 가정이다(대상자별로 앞 단계 제출 후 다음 단계 열림). 시연 회차 경로 — 팀원: 자기평가 → 팀장평가 → 임원평가 / 팀장: 자기평가 → 임원평가. 팀장 본인이 받는 단계 수와 임원 자기평가 여부는 미정.
- 이전 브라우저 데이터를 변환했을 때의 안내(상향평가 배정·응답·링크 제외 건수)도 화면에 표시하지 않는다. 변환 규칙은 `data-model.md` 참고.
- (2026-10-27 추가 삭제) 표 아래 범례·상태 설명과 "지금 작성할 차례인 사람" 아래 설명 문단도 화면에서 지웠다. 보관 내용:
  - 표의 "미완료"에는 작성 중(임시저장만 됨), 미시작(작성 가능하지만 시작 안 함), 대기(앞 단계가 제출되면 열림), 평가자 미지정이 모두 포함된다. 공백은 그 대상자의 경로에 없는 단계이며 미완료로 세지 않는다.
  - 지금 작성할 차례인 사람: 지금 바로 작성할 수 있는데 아직 제출하지 않은 평가가 있는 사람. 앞 단계를 기다리는 평가만 있는 사람은 포함하지 않는다.
- 화면 공통 상단의 검은 "시연 모드" 띠(가상 데이터·실제 로그인 아님 표시)는 이번 지시 대상이 아니라 그대로 둔다.
