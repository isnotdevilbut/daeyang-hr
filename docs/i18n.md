# 평가 참여자 화면 한국어·러시아어 (D-075, 2026-10-29)

## 방식: 번역문 미리 저장
- 고정 문구(버튼·안내·상태·오류)는 `src/i18n/index.ts` 사전에, 문항·도움말·선택지·평가영역 이름의 번역은 **문항 데이터 자체**(`question.i18n.ru`, `section.i18n.ru`)에 저장해 두고, 직원이 고른 언어로 보여 준다.
- 외부 번역 API·LLM API·브라우저 번역에 의존하지 않는다. API 키 입력·외부 서비스 가입·연결이 없고, 사용 중 외부로 번역을 요청하지 않는다(자동 확인: 다른 출처 요청 0건). 새 문장을 자동으로 번역하는 기능은 없다.
- 직원이 쓴 서술형 답, 이름·사번·팀 이름·회차 이름은 번역하지 않는다. 답은 선택지 ID·입력 원문 그대로 저장돼 언어와 무관하다.

## 범위
- 평가 참여자(사원·팀장·임원) 화면: 로그인(입력 항목·버튼·오류), 머리글(내 평가·직급·로그아웃·언어 선택), 내 평가 목록(사원·팀장 표, 임원 카드·필터)과 상태, 자기평가 응답 화면(평가영역·문항·도움말·선택지·필수 표시·화면/필수 응답 진행·이전/다음/임시저장/제출·제출 전 확인·누락 안내·저장 상태·완료 화면·제출 확인), 팀장·임원 평가 작성 화면(문항·선택지·버튼·저장 상태·등급 배정 현황·대상자 자기평가 참고 — 임원 화면만, D-079), 권한 없음 안내.
- 관리자 화면은 한국어. 관리자 문항 미리보기는 실제 화면과 같은 번역 데이터·같은 컴포넌트(ResponsePager·QuestionView)로 한국어·러시아어를 고를 수 있다(미리보기 답은 저장하지 않음).
- 언어 선택: 한국어 / Русский 두 가지. 같은 브라우저에 기억(`localStorage: daeyang-hr-lang`, 이전에 탭에만 저장한 값도 이어받음). 바꿔도 현재 화면 위치·입력한 답·선택·임시저장 상태는 그대로.
- 번역이 없는 항목은 한국어 원문으로 표시(노란 "번역 준비 중" 배너는 제거).

## 번역 초안
- 고정 문구 전체와 기본 목업 문항(2026 작업본 `tpl-draft`: 평가영역 8개, 문항 10개, 선택지 24개)의 러시아어는 개발 단계에서 직접 작성한 **초안**이다 — 회사 검수 전. 인사평가 문맥의 정중한 표현(вы-форма)을 쓰고, 문항 의미·평가 기준·선택지 순서·점수·필수 여부는 그대로다.
- 과거 원본 평가양식(2022·2025, 잠금 템플릿)은 제품 응답에 쓰지 않아 번역하지 않았다.
- 화면 폭 때문에 하단 "임시저장" 버튼은 러시아어로 짧게 «Сохранить»(저장 후 상태 문구는 «Черновик сохранён»).

## 관리자 번역 입력 위치
- 평가 관리 → 문항 관리 → 문항 "수정"(또는 문항 추가) 창 → **"러시아어 번역"** 접기 영역: 질문·도움말·선택지별 러시아어. 비워도 한국어 문항 저장 가능, 새 문항은 "미입력"으로 표시(자동 생성 아님).
- 평가영역 이름: 문항 관리의 영역 머리글 **RU** 버튼 → 러시아어 이름 입력.
- 선택지 번역은 선택지 고유 ID로 연결 — 선택지 순서를 바꿔도 번역·점수·응답 연결이 유지된다. 문항 복제(공용 함수)·평가 복제 시 번역도 함께 복사된다.
- 한국어 원문을 고치면 번역은 지우거나 덮어쓰지 않고, 관리자 편집 영역에만 "번역 재확인 필요"(영역은 "재확인")를 표시한다. 번역을 고쳐 저장하거나 "그대로 확인"을 누르면 해제된다(`basis` = 번역 기준 한국어 원문).

## 저장 데이터
- v8 → v9: 기본 문항·선택지·영역 중 ID가 같고 한국어 원문이 기본값과 글자 그대로 같은 항목에만 번역 초안을 붙인다. 사용자가 고친 문항·이미 있는 번역(사용자 작성 포함)은 건드리지 않는다. 직원·배정·응답·점수·문항/선택지 ID 변경 없음, 반복 실행 안전, 변환 전 데이터는 `daeyang-hr-mockup-v1-before-v9`.
