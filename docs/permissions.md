## 상향평가

2026-10-27 후속 확인으로 상향평가(팀원→팀장)는 없다(D-011). 관련 권한 행과 익명성 표시 규칙을 삭제했다.

## 평가자 역할 ≠ 운영 권한

팀장·임원이 평가자라는 사실만으로 인원·문항·회차 관리 권한을 주지 않는다. 운영담당자도 다른 사람의 평가를 대신 작성·제출할 수 없다(평가 작성 권한은 평가 참여자 본인에게만 있고, 화면에서 배정의 평가자 ID를 다시 확인한다).

## 확인이 필요한 질문

1. 차장님이 응답 원문·점수·리포트를 어디까지 열람·생성·내보내는가? "대표자만 열람"의 범위는?
2. 팀장이 팀원의 자기평가를, 임원이 팀장 평가를 참고할 수 있는가?
3. 보정 입력 권한은 담당자인가 대표자인가?

## 2026-10-27 로그인·역할 정리

- 접속 역할: 운영담당자 / 운영담당자·최종 조정 / 팀장 / 임원. **대표자 전용 화면·계정은 없다**(D-035). 대표자는 조직의 직책으로만 남는다.
- 마지막 열(운영담당자·최종 조정)은 대표님이 직접 쓸지 담당자가 승인 내용을 반영할지 정해지지 않아 목업에서 확인용으로 둔 가정이다. 실서비스 권한 아님.
- 평가자(팀장·임원)는 본인에게 배정된 평가만 보고 운영 메뉴는 없다. 다른 주소로 들어가면 "내 평가 작업"으로 돌아간다.
- ~~직원은 로그인 없이 개인 링크 + 사번 확인~~ → 2026-10-28 사번 로그인으로 대체(아래).
- 로그아웃하면 로그인 화면으로 가고, 뒤로 가기·직접 주소로도 관리 화면이 열리지 않는다.

## 2026-10-28 조직 관리 데이터 기반 로그인 (D-059)

- 평가 참여자: 아이디 = 이름, 비밀번호 = 사번. 조직 관리의 현재 재직 직원과 대조하며 별도 계정 목록은 없다. 삭제된 직원은 로그인·기존 세션 모두 막힌다.
- 역할(직원·팀장·임원)은 매번 현재 조직 정보로 정한다. 운영담당자 권한은 admin·admin-final 고정 계정으로만 생기며 직원 등록·임원 지정으로는 생기지 않는다.
- 저장·제출 직전에 로그인 직원이 유효하고 그 배정의 평가자인지 다시 확인한다.
- ⚠ 이름·사번은 다른 사람이 알 수 있는 정보라 실제 인증 수단으로 쓰면 안 된다. 목업 확인용이다(Q-18).

## 2026-10-28 사번 로그인 통일 (D-048~D-050) — 계정 방식은 D-059로 대체

- 접속 역할: 운영담당자 / 운영담당자·최종 조정 / 직원 / 팀장 / 임원. 평가 참여자는 사번 + 비밀번호로 로그인하고, 역할은 연결된 직원의 조직 정보로 정한다(임원 > 팀장 > 직원). 로그인 화면에서 역할을 고르지 않는다.
- 평가 작성(`evaluate`)은 직원·팀장·임원만. 어떤 평가든 **배정의 평가자 ID = 로그인한 직원 ID**일 때만 열리고, 선행 단계가 남아 있으면 열리지 않는다. 운영담당자에게는 작성 권한이 없다.
- 참여자가 관리 화면 주소로 들어가면 "내 평가"로, 운영담당자가 평가 작성 주소로 들어가면 진행 현황으로 돌아간다.
- 이전 개인 링크 주소(`#/e/…`)는 링크의 직원 정보를 쓰지 않는다. 로그인 전이면 로그인 화면, 로그인 후면 로그인한 본인의 첫 화면.
- 개인 상세의 "미완료 평가"는 운영담당자가 작성 현황을 확인하는 용도다. 사칭 로그인·대신 작성·대신 제출 기능은 없다.
- ⚠ 목업 로그인은 브라우저에서 가상 계정을 대조할 뿐 실제 보안 인증이 아니다. 실제 계정 발급·비밀번호 초기화·서버 인증은 별도 과제(Q-18).

## 2026-10-28 세 직급과 권한 (D-068)

- 직급은 **임원·팀장·사원** 세 가지이며 화면의 평가 역할만 정한다(로그인 역할 표시도 사원·팀장·임원). 임원 직급(또는 직원 창에서 임원으로 지정)은 **운영 관리 권한을 주지 않는다** — 운영 권한은 여전히 admin·admin-final 고정 계정으로만.
- 팀장 직급 = 실제 팀장 연결. 팀장 지정·해제는 운영담당자의 조직 관리(직원 창·팀 관리·업로드)에서만.
- 팀장·임원 자기평가 켜기/끄기는 운영담당자만(평가 관리), 확정 회차는 불가. 임원은 자기평가가 켜진 회차에서만 본인 자기평가를 작성하고, 평가자로서의 배정(3단계)은 그와 무관하다.
- 보정 사유는 선택 입력이며 보정 권한(운영담당자)은 바뀌지 않는다.
