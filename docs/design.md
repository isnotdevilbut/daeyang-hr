## 드롭다운 (2026-10-28, D-055)
- 기본 `select` 그대로(키보드·모바일 선택 기능 유지), `appearance: none`으로 기본 화살표를 숨기고 배경 이미지로 아이콘을 그린다.
- 아이콘: 28×28 둥근 사각형(파랑 9% → 청록 16% 반투명) + 가는 chevron(선 1.8px), 크기 고정(`background-size: 28px 28px`), 오른쪽에서 10px 위치 → chevron 오른쪽 여백 약 17px.
- 글자: 오른쪽 안쪽 여백 50px, 긴 값은 말줄임, `max-width: 100%`.
- 상태: hover 청록 테두리·조금 진한 아이콘 / 키보드 포커스 청록 테두리 + 기존 링 / 비활성 회색 바탕·회색 아이콘·not-allowed. 흰 바탕·얇은 테두리·약한 그림자, 애니메이션 없음.

## 공통 레이아웃·메뉴 인터랙션 (2026-10-28, D-067)
- 레이아웃: `body` 바깥 배경(연한 블루·시안) → 흰 헤더(그대로) → `.app-shell > .app-panel` 큰 둥근 패널 → 기존 `.page`. 패널은 시각 구조만이며 스크롤은 문서 하나.
  패널에 overflow·transform·filter·backdrop-filter를 넣지 말 것(고정 모달·드롭다운이 갇히거나 잘림).
- 계정 영역: `.user-id` = `.avatar`(이름 첫 글자 또는 사람 아이콘, 블루·시안 1.5px 테두리) + `.role-pill`(이름 / 역할). 클릭 동작 없음.
- 메뉴: `PaintNav`(src/components/PaintNav.tsx). 링크마다 `.paint` 안에 `i.p1~p3`, 포인터 좌표·속도는 `--mx --my --sp --ang`. 선택 표시(`.active`)는 기존 그대로.
  `(hover: none)`·`(pointer: coarse)`·`prefers-reduced-motion`에서는 레이어를 끈다.

## 배경·종이·포인터 빛·메뉴 선택·카드 선택 (2026-10-28, D-068 — D-067 메뉴 번짐 대체)

- 배경: 파랑·청록 그라데이션 채도를 조금 올림(+ 아래쪽 파랑 한 겹). 종이(.app-panel)는 더 불투명(95%)하고 뒤에 넓고 부드러운 그림자(0 30px 80px).
- 헤더 아래 그라데이션 띠(관리자·모바일 머리글) 제거.
- 포인터 빛(`PointerGlow`): 파란 바깥 영역과 흰 헤더 안에서 포인터를 따라 번지는 둥근 빛(청록 → 파랑 → 연보라). 종이(`.app-shell`, z 1)보다 아래 층이라 종이 위에 올라오지 않고, 포인터가 종이·모달 위에 있으면 꺼진다. pointer-events 없음. 터치·모션 감소에서는 없음.
- 메뉴 선택(`.nav-sel`): 가장자리가 부드러운 그라데이션 하나가 선택 메뉴 뒤에 머무르고 메뉴가 바뀌면 이동. hover로 사라지지 않으며 배경 빛과 별개. 누르면 짧은 물결(0.52초, 마우스·펜만). 터치: 선택 표시만. 모션 감소: 이동·물결 없이 정적.
- 진행 현황 카드: 선택 = 유리 같은 그라데이션 + 윗면 광택 + 청록 테두리(다섯 카드 공통, 하나만), hover = 테두리·살짝 떠오름(선택과 구분), 키보드 포커스 링.
- 진행 표 셀: ✓ 완료(초록)·미완료(빨강)·해당 없음은 작은 회색 "—"(범례 없음).

## 상단 내비게이션: 배경 위 글자 + 번지는 빛 (2026-10-28, D-069 — D-068 메뉴 상자·배경 빛 대체)

- 헤더 배경 = `--page-bg`(body::before와 같은 그라데이션, `background-attachment: fixed`) → 헤더와 아래 블루 배경이 한 장처럼 이어짐. 스크롤 시 지나가는 작업 화면은 이 배경이 가린다.
- 빛 층 `.aurora` 두 개(헤더 안 `aurora-header` — 헤더 `clip-path`로 헤더 영역만, 작업 화면 뒤 `aurora-page` — `.app-shell`(z 1) 아래)에 같은 내용을 그려 경계에서 잘리지 않는다. 좌표는 루트 CSS 변수(`--sx --sy --sw` 선택, `--gx --gy` 포인터, `data-sel`·`data-hov`).
- 선택 빛 `.a-sel`: 메뉴 폭 + 190px × 150px, 청록(46%)·남색(30%)·연보라(30%) 세 겹이 6.5·9·11초 주기로 이동·늘어남·회전 → 물 위의 빛처럼 형태 변화. 이동 0.76초.
- hover 빛 `.a-hov`: 260 × 160px 옅은 청록·연보라, 포인터를 0.42초 지연으로 따라옴. 흰 작업 화면·모달·로그인 카드 위에서는 꺼짐.
- 파동 `.a-ripple`: 클릭 1.15초 고리(5배까지 퍼짐), 새 메뉴 진입 0.9초 약한 고리. 두 층에 같은 순간 추가.
- 터치: 선택 빛만. 움직임 줄이기: 흔들림·이동·파동·hover 빛 없이 선택 빛 정적.
- body 배경은 투명(바탕색은 :root) — 이전에는 body 바탕이 고정 블루 배경을 가려 회백색으로 보였음.
