# 화면 목록 (목업 기준)

표기: **[시연]** = 가상 저장·가상 계산·미리보기만 동작, **[미구현]** = 버튼·안내만 있고 실서비스 단계에서 구현.

## 공통

| 화면 | 주소 | 내용 |
|---|---|---|
| 로그인 (목업) | `#/login` | 로고·제목·"시연용 로그인"·아이디(사번)·비밀번호(가림/보기)·로그인, 접히는 "시연 계정 보기"(사번·이름·역할·팀). 비로그인 상태의 모든 관리·평가 주소는 여기로. 이전 개인 링크 주소에서 오면 짧은 안내 |
| 개발 도구 | `#/dev` | 시연 계정 목록, 시연 데이터 초기화. 제품 화면에서 링크하지 않음 |
| 헤더 사용자 영역 | 관리·평가자 화면 | 역할(또는 이름·역할) 표시 + 로그아웃 |

별도 HOME 없음. 로그인한 계정의 역할에 따라 첫 화면으로 이동한다(운영담당자 → 진행 현황, 직원·팀장·임원 → 내 평가). 대표자 전용 화면은 없다(D-035).

## 직원 응답 화면(모바일)

| # | 화면 | 주소 | 주요 기능 |
|---|---|---|---|
| C1 | 자기평가 작성 | `#/eval/self/:assignmentId` | 로그인한 본인의 자기평가만. 언어 선택 한국어 / Русский(본인 세션에 유지, 러시아어는 번역 미구현 안내), 영역별 단계 진행, 큰 글씨·큰 버튼, 화면 수만큼 나눈 칸 진행 표시(완료·현재·미작성) + "화면 n / N"·"필수 응답 x / y개 완료", 임시저장, 검토(누락 안내), 제출, 완료, 제출 내용 보기 |

이전 주소 `#/e/…`(개인 링크)와 `#/links`는 화면이 없다. 로그인 전이면 로그인 화면, 로그인 후면 본인의 첫 화면으로 간다(D-049).

직원 화면에는 점수·등급·타인 응답·최종 결과가 나타나지 않는다.


이전 주소 `#/admin/templates`, `#/admin/templates/:id` → 문항 관리 / `#/admin/cycles` → 평가 설정 / `#/admin/cycles/:id` → 그 회차의 평가자·가중치 설정 / `#/admin/open-questions` → 평가 관리 (D-023, D-024).
