# 직원 명단 업로드 시험 파일 (가상 데이터)

조직 관리 → 일괄 업로드에서 올려 보는 시험용 CSV입니다. 이름·사번은 모두 가상이며 실제 직원 정보가 아닙니다.
팀·직무·직급 이름은 시연 데이터 기준(경영기획팀·설계팀·생산팀·현장팀 / 관리직·생산직 / 임원·팀장·사원)입니다.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `0_직원명단_양식.csv` | 머리글만(팀,직급,이름,직무,사번) | 0행 — 등록 버튼 꺼짐. 이 파일에 행을 채워 쓰는 양식 |
| `1_정상_양식순서.csv` | 양식 순서 그대로 3명 | 3명 등록 |
| `2_열순서_바꿈.csv` | 사번,이름,직무,직급,팀 순서 2명 | 머리글 이름으로 읽어 2명 등록(값이 뒤섞이지 않음) |
| `3_새열_추가.csv` | 양식 + 근무지·비고 열 | 분류 기준 '근무지'가 없으면 두 열 모두 "쓰지 않는 열"로 표시하고 2명 등록. 조직 관리에서 분류 기준 '근무지'를 만든 뒤 올리면 근무지 값도 함께 등록, 비고만 무시 |
| `13_명단_최소열_중복포함.csv` | 성명·사원번호·부서 3열만, 파일 안 중복 1행·기존 사번 1행 | '중복 사번은 빼고 업로드'를 켜면 2명 등록(직급 사원·직무 첫 직무), 끄면 중복 때문에 등록 안 됨 |
| `15_명단_기존직원_새칼럼값.csv` | 이미 등록된 직원 2명 + 새 '근무지' 값, 파일 안 같은 행 1개, 새 직원 1명('근무지' 칼럼을 먼저 만든 뒤) | 기존 2명은 근무지만 바뀜(팀·이름은 그대로), 같은 행은 '중복 데이터는 빼고 업로드'를 켜면 건너뜀, 새 직원 1명 등록 |
| `4_오류_확인용.csv` | 없는 팀·없는 직급·빈 이름·없는 직무·파일 안 중복 사번·기존 사번 | 5행 모두 오류, 아무도 등록하지 않음 |

- 필수 열: **이름·사번·팀**(성명·사원번호·부서·소속 등 다른 이름도 인식). 직급이 없으면 '사원', 직무가 없으면 첫 번째 직무로 넣고 미리보기에 안내합니다. 열 순서는 달라도 됩니다.
- '중복 데이터는 빼고 업로드' 체크: 중복 = **같은 내용**(이미 등록된 직원과 내용이 같거나 파일 안에 같은 행이 또 있음). 켜면 건너뛰고 나머지만, 끄면 중복이 있을 때 아무것도 등록하지 않습니다. 이미 등록된 직원이라도 **칼럼 값이 다르면 새 데이터**로 그 칼럼 값만 바꿉니다(팀·직급·이름·직무는 바꾸지 않음). 같은 사번이 파일 안에서 다른 내용으로 두 번 나오면 오류입니다.
- 사번은 글자로 저장하세요(엑셀에서 숫자로 바뀌면 앞자리 0이 사라짐). CSV는 UTF-8(BOM)·EUC-KR 모두 읽습니다.
- 같은 파일을 두 번 올리면 두 번째는 "이미 등록된 사번" 오류(또는 "건너뛰기" 선택)입니다.

## 기존 직원 칼럼 값 채우기 (조직 관리 → 일괄 업로드 → 아래쪽 '칼럼 값 채우기')

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `14_칼럼값_이름만.csv` | 이름·근무지(사번 없음) | 이름으로 직원을 찾아 근무지를 채움(동명이인은 그 행만 사번 필요) |
| `12_칼럼값_채우기.csv` | 사번·이름·근무지·비고 | 직원 목록에서 '+ 칼럼 추가'로 '근무지'(텍스트)를 먼저 만든 뒤 올리면 4명의 근무지가 채워짐. 이름 열은 바꾸지 않는 열, 비고는 쓰지 않는 열(칼럼을 만들지 않음) |

- 사번(없으면 이름)으로 재직 중인 직원을 찾고, **이미 만든 칼럼**의 값만 채웁니다. 필요한 열은 사번 또는 이름 + 칼럼 이름 열뿐입니다. CSV의 새 열로 칼럼이 저절로 생기지 않습니다.
- 빈 칸은 그대로 둡니다(지우지 않음). 팀·직급·이름·직무는 바꾸지 않습니다(직원 수정 창에서).
- 미리보기에서 '이전 → 새 값'을 확인한 뒤 저장합니다. 오류가 하나라도 있으면 아무것도 바꾸지 않습니다.

## 문항 일괄 업로드 (평가 관리 → 문항 관리 → 엑셀·CSV 가져오기)

직원 명단 업로드와 같은 방식입니다: 파일 선택(.xlsx/.csv, 시트가 여럿이면 시트 선택) → 미리보기·행별 확인 → 오류가 하나라도 있으면 아무것도 넣지 않음.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `5_문항_양식.csv` | 머리글만 | 0행 — 이 파일에 행을 채워 쓰는 양식 |
| `6_문항_예시.csv` / `7_문항_예시.xlsx` | 공통 평가표용 유형별 문항 7개(서술형·5점 척도·O/X·단일선택·등급) | 7개 모두 문항으로(같은 이름의 영역 뒤, 없으면 새 영역) |
| `9_팀원팀장_문항_예시.csv` | 적용평가 열 없이 3개 | '팀원→팀장 평가표' 탭에서 올리면 모두 팀원→팀장평가 문항으로 |
| `8_문항_오류_확인용.csv` | 빈 질문·숫자가 아닌 배점·선택지 1개(모르는 유형은 오류 아님) | 오류 2행 — 아무것도 넣지 않음 |
| `10_문항_질문만.csv` | 질문 열 하나만 | 모두 '미분류' 영역의 긴 서술형으로 |
| `11_영역표_두표_예시.xlsx` | 한 시트에 '팀장 본인평가 예시'·'임원 및 팀장 상향평가 예시' 두 표(구분·배점·평가내용, 합계 줄) | 창에서 '표'를 골라 올림 — 한 줄 = 영역 하나(배점 = 영역 배점, 평가내용 = 그 영역의 5점 척도 문항·영역 설명), 합계 줄은 넣지 않고 확인만 |

- 꼭 필요한 열은 **질문** 하나입니다(문항·문항내용도 인식). 영역이 없으면 '미분류', 유형이 없거나 모르는 유형이면 긴 서술형(선택지가 있으면 단일선택)으로 들어가고 미리보기에 안내가 나옵니다 — 문항 관리에서 나중에 고치면 됩니다.
- 선택 열: 영역·유형·필수(Y/N, 비우면 Y)·선택지·선택지점수·적용평가·배점(문항 배점)·도움말. 열 순서는 달라도 됩니다.
- 유형: 짧은 주관식 / 긴 서술형 / 단일선택 / O/X / 5점 척도 / 등급. 여러 값(선택지·점수·적용평가)은 `|`로 구분.
- 적용평가: 자기 / 팀원→팀장 / 팀장 / 임원. 비우면 자기평가(팀원→팀장 평가표에 올리면 팀원→팀장평가).
- 올리는 평가표의 적용 평가와 맞지 않는 문항(예: 공통 평가표에 팀원→팀장평가)은 어디에도 보이지 않으므로 오류로 표시합니다.
- **구분·배점·평가내용 표**(영역마다 한 줄): 구분 = 영역, 배점 = 영역 배점, 평가내용 = 질문(5점 척도). 한 영역에 여러 줄이면 배점은 문항 배점으로 읽습니다. 영역 배점을 따로 주려면 '영역배점' 열을 쓰세요.
- 한 시트에 표가 여러 개면 표 위의 제목으로 고릅니다(팀원→팀장 평가표 탭은 '상향', 팀장 자기평가표 탭은 '본인·자기'가 든 표가 먼저 선택).
- 이름이 없는 열(예: 비고)은 "쓰지 않는 열"로 표시만 하고 넣지 않습니다.

## 번역(러시아어) 올리기 — D-250
- 문항 파일에 **'러시아어'** 열을 붙이면 질문 번역으로 읽습니다. 머리글에 '러시아어'·'번역'·'RU'·'Russian'이 들어가면 번역 열로 봅니다. 선택지·도움말·영역 번역은 `선택지(러시아어)`(| 로 구분, 선택지 개수와 같게)·`도움말(러시아어)`·`영역(러시아어)`.
- 이미 있는 문항에 번역만 넣을 때: `16_번역_러시아어.csv`처럼 **질문 + 러시아어** 두 열이면 됩니다. 가져오기 창에서 '번역만 반영'이 자동 선택되고, 같은 질문을 찾아 러시아어만 저장합니다(문항·응답·점수는 그대로, 없는 질문은 건너뜀).
