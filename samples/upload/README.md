# 직원 명단 업로드 시험 파일 (가상 데이터)

조직 관리 → 일괄 업로드에서 올려 보는 시험용 CSV입니다. 이름·사번은 모두 가상이며 실제 직원 정보가 아닙니다.
팀·직무·직급 이름은 시연 데이터 기준(경영기획팀·설계팀·생산팀·현장팀 / 관리직·생산직 / 임원·팀장·사원)입니다.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `0_직원명단_양식.csv` | 머리글만(팀,직급,이름,직무,사번) | 0행 — 등록 버튼 꺼짐. 이 파일에 행을 채워 쓰는 양식 |
| `1_정상_양식순서.csv` | 양식 순서 그대로 3명 | 3명 등록 |
| `2_열순서_바꿈.csv` | 사번,이름,직무,직급,팀 순서 2명 | 머리글 이름으로 읽어 2명 등록(값이 뒤섞이지 않음) |
| `3_새열_추가.csv` | 양식 + 근무지·비고 열 | 분류 기준 '근무지'가 없으면 두 열 모두 "쓰지 않는 열"로 표시하고 2명 등록. 조직 관리에서 분류 기준 '근무지'를 만든 뒤 올리면 근무지 값도 함께 등록, 비고만 무시 |
| `4_오류_확인용.csv` | 없는 팀·없는 직급·빈 이름·없는 직무·파일 안 중복 사번·기존 사번 | 5행 모두 오류, 아무도 등록하지 않음 |

- 필수 열: 팀·직급·이름·직무·사번(하나라도 없으면 파일 오류). 열 순서는 달라도 됩니다.
- 사번은 글자로 저장하세요(엑셀에서 숫자로 바뀌면 앞자리 0이 사라짐). CSV는 UTF-8(BOM)·EUC-KR 모두 읽습니다.
- 같은 파일을 두 번 올리면 두 번째는 "이미 등록된 사번" 오류(또는 "건너뛰기" 선택)입니다.
