# 직원 명단 업로드 시험 파일 (가상 데이터)

조직 관리 → 일괄 업로드에서 올려 보는 시험용 CSV입니다. 이름·사번은 모두 가상이며 실제 직원 정보가 아닙니다.
팀·직무·직급 이름은 시연 데이터 기준(경영기획팀·설계팀·생산팀·현장팀 / 관리직·생산직 / 임원·팀장·사원)입니다.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `0_직원명단_양식.csv` | 머리글만(팀,직급,이름,직무,사번) | 0행 — 등록 버튼 꺼짐. 이 파일에 행을 채워 쓰는 양식 |
| `1_정상_양식순서.csv` | 양식 순서 그대로 3명 | 3명 등록 |
| `2_열순서_바꿈.csv` | 사번,이름,직무,직급,팀 순서 2명 | 머리글 이름으로 읽어 2명 등록(값이 뒤섞이지 않음) |
| `3_새열_추가.csv` | 양식 + 근무지·비고 열 | 분류 기준 '근무지'가 없으면 두 열 모두 "쓰지 않는 열"로 표시하고 2명 등록. 조직 관리에서 분류 기준 '근무지'를 만든 뒤 올리면 근무지 값도 함께 등록, 비고만 무시 |
| `4_오류_확인용.csv` | 없는 팀·없는 직급·빈 이름·없는 직무·파일 안 중복 사번·기존 사번 | 5행 모두 오류, 아무도 등록하지 않음 |

- 필수 열: 팀·직급·이름·직무·사번(하나라도 없으면 파일 오류). 열 순서는 달라도 됩니다.
- 사번은 글자로 저장하세요(엑셀에서 숫자로 바뀌면 앞자리 0이 사라짐). CSV는 UTF-8(BOM)·EUC-KR 모두 읽습니다.
- 같은 파일을 두 번 올리면 두 번째는 "이미 등록된 사번" 오류(또는 "건너뛰기" 선택)입니다.

## 문항 일괄 업로드 (평가 관리 → 문항 관리 → 엑셀·CSV 가져오기)

직원 명단 업로드와 같은 방식입니다: 파일 선택(.xlsx/.csv, 시트가 여럿이면 시트 선택) → 미리보기·행별 확인 → 오류가 하나라도 있으면 아무것도 넣지 않음.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `5_문항_양식.csv` | 머리글만 | 0행 — 이 파일에 행을 채워 쓰는 양식 |
| `6_문항_예시.csv` / `7_문항_예시.xlsx` | 공통 평가표용 유형별 문항 7개(서술형·5점 척도·O/X·단일선택·등급) | 7개 모두 문항으로(같은 이름의 영역 뒤, 없으면 새 영역) |
| `9_팀원팀장_문항_예시.csv` | 적용평가 열 없이 3개 | '팀원→팀장 평가표' 탭에서 올리면 모두 팀원→팀장평가 문항으로 |
| `8_문항_오류_확인용.csv` | 빈 질문·없는 유형·숫자가 아닌 배점·선택지 1개 | 오류 2행 — 아무것도 넣지 않음 |

- 필수 열: 영역·질문·유형. 선택 열: 필수(Y/N, 비우면 Y)·선택지·선택지점수·적용평가·배점(문항 배점)·도움말. 열 순서는 달라도 됩니다.
- 유형: 짧은 주관식 / 긴 서술형 / 단일선택 / O/X / 5점 척도 / 등급. 여러 값(선택지·점수·적용평가)은 `|`로 구분.
- 적용평가: 자기 / 팀원→팀장 / 팀장 / 임원. 비우면 자기평가(팀원→팀장 평가표에 올리면 팀원→팀장평가).
- 올리는 평가표의 적용 평가와 맞지 않는 문항(예: 공통 평가표에 팀원→팀장평가)은 어디에도 보이지 않으므로 오류로 표시합니다.
- 이름이 없는 열(예: 비고)은 "쓰지 않는 열"로 표시만 하고 넣지 않습니다.
