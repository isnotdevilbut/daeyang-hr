# 대양롤랜트 인사평가 — 빈 상태로 시작하는 버전

원본 웹앱(https://daeyang-hr-mockup.onrender.com)과 화면·기능이 같고, **데이터가 하나도 없는 상태**로 시작합니다.
직원·팀·평가·문항은 화면에서 만들거나 `samples/` 폴더의 샘플 CSV(모두 가상)를 올려 채웁니다.

## 실행

```bash
npm ci           # 처음 한 번 (설치)
npm run dev      # 내 컴퓨터에서 켜기 → 브라우저에서 http://localhost:5173
npm test         # 자동 테스트
npm run build    # 배포용 파일 만들기(dist 폴더)
```

## 관리자 로그인
- 아이디 `admin`, 비밀번호는 `src/admin-password.ts` 파일에서 각자 정합니다.
- 시연용입니다. 비밀번호가 사이트 파일 안에 그대로 들어가 누구나 볼 수 있으니 다른 곳에서 쓰는 비밀번호는 쓰지 마세요.
- 직원 로그인: 아이디 = 이름, 비밀번호 = 사번(올린 명단의 값). 실제 보안 인증이 아닙니다.

## 샘플 CSV (`samples/`)

| 파일 | 올리는 곳 |
|---|---|
| `1_직원명단.csv` | 조직 관리 → 일괄 업로드 (먼저 조직 설정에서 팀 4개를 만든 뒤) |
| `2_문항_자기평가(사원).csv` | 평가 관리 → 문항 관리 → '자기평가(사원)' 탭 → 엑셀·CSV 가져오기 (러시아어 번역 포함) |
| `3_문항_팀장평가표.csv` | '팀장평가표' 탭 |
| `4_문항_임원평가표.csv` | '임원평가표' 탭 |
| `5_문항_팀장자기평가표.csv` | '팀장 자기평가표' 탭 |
| `6_문항_팀원-팀장평가표.csv` | '팀원→팀장 평가표' 탭 |
| `7_문항_임원상향평가표.csv` | '임원 상향평가표' 탭 |

## 데이터
- 서버·DB 없음. 방문자 브라우저(localStorage)에만 저장되고 다른 사람·기기와 공유되지 않습니다.
- 처음 상태로 되돌리기: 주소 뒤에 `#/dev` → '시연 데이터 초기화'.
- 실제 인사 자료(실명·사번·평가 결과)는 넣지 마세요.

## 배포
- GitHub 저장소 → Render Blueprint(`render.yaml`) 정적 사이트(무료). 빌드 `npm ci && npm run build`, 게시 폴더 `dist`.
